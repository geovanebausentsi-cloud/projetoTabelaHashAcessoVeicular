Objetivo:

Implementar uma estrutura de dados utilizando tabela de hash (hash table) para cadastrar placas de veículos e buscar rapidamente informações associadas a cada uma delas.

Contextualizando:

A prefeitura de uma cidade está digitalizando o sistema de controle de acesso a uma área restrita.
 Cada veículo autorizado deve ter
  sua placa cadastrada no sistema com informações básicas,
   como nome do proprietário e modelo do carro.

Você foi contratado para implementar uma solução simples que:

Cadastre placas de veículos;
Permita buscar rapidamente uma placa;
E exiba as informações armazenadas.
Requisitos da implementação:

Criar uma tabela hash personalizada (sem usar objetos prontos como Map ou Set do JavaScript);

Utilizar uma função de hashing simples baseada em somatório dos caracteres da placa;

Criar uma interface de inserção e busca com form HTML simples;

Armazenar pelo menos 50 entradas diferentes;

Realizar busca de 3 placas existentes e 2 inexistentes, mostrando o comportamento da busca.

Entrega esperada:

Código funcional (em JavaScript); [12 pontos]
Registro de testes feitos (com placas existentes e inexistentes); [4 pontos]
Captura de tela (ou vídeo curto) mostrando uso da função de busca com feedback.
Comentários no código explicando o funcionamento; [4 pontos]
